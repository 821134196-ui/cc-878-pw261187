  3. 重试发生在代理向下一个 SRV/A 结果建连时。
    DNS_TIMEOUT 是解析阶段；ECONNREFUSED / HEADER_TIMEOUT 是数据面尝试失败。

语义说明

周期刷新：代理每 3 秒向进程内演示 DNS 查询 SRV，再解析每个 target 的 A 记录；控制面改记录后也可手动立即刷新。

优雅排空：端点集合变化才新建 Agent。旧 Agent 的 free socket 立即 destroy，active request 继续；响应结束后 socket 关闭且代际注销。

可区分超时：DNS_TIMEOUT 表示某个解析结果无响应但其他 A/SRV 结果可用；HEADER_TIMEOUT 表示 TCP 已连到 tarpit 但没有 HTTP 响应头。

安全重试：仅对 GET/HEAD/OPTIONS 且响应头尚未发送时尝试下一个端点；流式响应一旦开始就不能换源重发。
